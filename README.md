## 🦊 NATSUMI Project

**NATSUMI**는 여우 콘셉트의 AI 캐릭터를 기반으로 한 감정형 AI 프로젝트입니다.

> 단순한 챗봇이 아니라, 사용자의 말에 반응하고 감정과 말투를 유지하며 커뮤니티 안에서 하나의 캐릭터처럼 함께하는 AI를 목표로 합니다.

### 주요 목표

- 🤖 Gemini 기반 자연어 대화 시스템 구축
- 🦊 여우 콘셉트 AI 캐릭터 구현
- 💬 Discord 서버와 연동되는 AI 봇 개발
- 🎭 감정 기반 응답 및 츤데레 스타일 반응 설계
- 🌐 웹 / 앱 / Discord / 게임 환경으로 확장 가능한 구조 제작
